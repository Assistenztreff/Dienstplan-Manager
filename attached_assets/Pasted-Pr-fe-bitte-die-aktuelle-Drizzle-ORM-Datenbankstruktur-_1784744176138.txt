Prüfe bitte die aktuelle Drizzle-ORM-Datenbankstruktur im Projekt (z. B. in `shared/schema.ts` oder `db/schema.ts`) und erweitere sie typsicher um die folgenden Datenmodelle für die Dienstplan-App. 

Das Datenmodell muss datenbankunabhängig aufgebaut sein, sodass es mit PostgreSQL (Replit) als auch später mit MySQL/MariaDB (All-Inkl) funktioniert.

Bitte stelle sicher, dass folgende Tabellen und Felder enthalten sind:

1. `users` (Plattform-Benutzer):
   - `id`: Text / Primary Key (UUID)
   - `name`: Text
   - `email`: Text / Unique
   - `role`: Text (Enum/Union: 'PRIVATPERSON' | 'DIENSTLEISTER' | 'ADMIN') - Default: 'PRIVATPERSON'
   - `logoUrl`: Text (Optional, für Conditional Rendering beim Dienstleister)
   - `createdAt`: Timestamp

2. `assistenzKraefte` (Mitarbeiter):
   - `id`: Text / Primary Key (UUID)
   - `userId`: Text (Foreign Key auf users.id)
   - `vorname`: Text
   - `nachname`: Text
   - `initials`: Text (z. B. "CN")
   - `colorTag`: Text (Barrierefreie Tailwind-Farbklasse, z. B. "bg-lime-200 text-lime-950")
   - `stundenlohn`: Real / Double Precision (in Euro)
   - `sollStundenMonat`: Real / Double Precision (vertragliche Soll-Stunden)
   - `createdAt`: Timestamp

3. `shifts` (Schichten & Ereignisse):
   - `id`: Text / Primary Key (UUID)
   - `assistenzKraftId`: Text (Foreign Key auf assistenzKraefte.id)
   - `startTime`: Timestamp
   - `endTime`: Timestamp
   - `type`: Text (Enum/Union: 'REGULAR' | 'BEREITSCHAFT' | 'VERTRETUNG' | 'TEAMSITZUNG' | 'KRANKHEIT' | 'URLAUB') - Default: 'REGULAR'
   - `pauseMinuten`: Integer - Default: 0
   - `isNachtschicht`: Boolean - Default: false
   - `notes`: Text (Optional, z. B. Notizen oder Jitsi-Meeting-Link)
   - `createdAt`: Timestamp

Implementiere oder erweitere zusätzlich die typsicheren Zod-Schemata (insertUserSchema, insertAssistenzKraftSchema, insertShiftSchema) sowie die TypeScript-Typen für den Export. Führe anschließend `npm run db:push` oder die Drizzle-Migrationen aus, um die Datenbank zu aktualisieren.
